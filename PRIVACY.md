# Règles de confidentialité de Pica

_Dernière mise à jour : 30 octobre 2026_

Pica est une extension de navigateur gratuite et open source (licence MIT) qui ajoute des outils de mise en forme dans l'éditeur de posts de LinkedIn. Cette page explique quelles données l'extension utilise et ce qu'elle en fait.

**En résumé : Pica ne collecte, ne transmet et ne vend aucune donnée. Tout reste sur votre appareil.**

## Données utilisées

Pour fonctionner, Pica utilise :

- **Le texte que vous écrivez dans l'éditeur de LinkedIn**, uniquement pour le mettre en forme (gras, italique, listes, Markdown, aération, nettoyage du collage) et compter les caractères. Ce traitement a lieu dans votre navigateur.
- **Vos brouillons**, enregistrés automatiquement pendant que vous écrivez.
- **Vos modèles de posts** et les valeurs de leurs variables.
- **Vos réglages** (fonctionnalités activées ou désactivées).

Les brouillons, les modèles et les réglages sont enregistrés dans le stockage local de votre navigateur, sur votre appareil.

## Ce que Pica ne fait pas

- Aucune requête réseau : l'extension n'envoie rien à un serveur, ni au développeur ni à un tiers.
- Aucune mesure d'audience, aucun traceur, aucune publicité.
- Aucune vente, location ou communication de données à des tiers.
- Aucune lecture de vos messages, de votre profil ou d'autres pages que l'éditeur de LinkedIn.
- Aucun code chargé à distance : tout le code est inclus dans l'extension et consultable publiquement.

## Permissions demandées

- **`storage`** : enregistrer localement vos brouillons, modèles et réglages.
- **Accès à linkedin.com** : afficher la barre de mise en forme dans l'éditeur de posts. L'extension ne s'exécute sur aucun autre site.

## Conservation et suppression

Vos données restent sur votre appareil tant que vous ne les supprimez pas. Vous pouvez :

- supprimer un brouillon ou un modèle depuis l'extension ;
- tout effacer en désinstallant l'extension, ce qui supprime son stockage local.

## Code source

Le code de Pica est public. Vous pouvez vérifier ces engagements sur [github.com/shadow3312/linkedin-formatter](https://github.com/shadow3312/linkedin-formatter).

## Modifications

Toute modification de ces règles sera publiée sur cette page, avec une nouvelle date de mise à jour. Si une future version devait traiter des données autrement, ces règles seraient mises à jour avant la publication de cette version.
